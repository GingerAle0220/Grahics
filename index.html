1. ベクトル・行列計算の復習

ベクトル表現

  • 座標値を「原点からのベクトル」で表す。成分は縦1列の行列で表す。例：座標(1,1,0) → a = (1,1,0)ᵀ
  • ベクトルは「長さと方向」を表すもの。始点がどこでも、長さと方向が等しければ同じベクトル。
  • 加算＝ベクトルの継ぎ足し。各成分（行ごと）に足し算。例：(1,1)+(1,2)=(2,3)
  • 減算 c = a − b ＝「bの先端からaの先端に向かうベクトル」（a = b + c になる）。各成分ごとに引き算。
▶ 例題：(1,0,0)の点を(1,1,3)に移動したい。移動量は？ (1,1,3) − (1,0,0) = (0,1,3) → (tx,ty,tz) = (0,1,3)

行列の乗算

2次元: x' = a00·x + a01·y y' = a10·x + a11·y （a' = A a） 3次元: x' = a00x + a01y + a02z y' = a10x + a11y + a12z z' = a20x + a21y + a22z 3×3同士: C = AB, cij = Σk aik·bkj
重要：合成変換 行列の積は交換できない（AB ≠ BA）。Bの変換のあとにAの変換 → 行列は AB（右側が先に作用）。
合成しても3×3行列1つになる。
▶ 例題：x=0平面の鏡映 → x軸に沿ってa(=tanα)だけz軸を傾けるスキュー。合成行列は？ 鏡映 B = diag(−1,1,1)、スキュー A = [[1,0,a],[0,1,0],[0,0,1]]
AB = [[−1,0,a],[0,1,0],[0,0,1]]
▶ 問：x方向2倍、y方向6倍、z方向1/3倍にしたあと、z軸中心に+30°回転 行列 = Rz(30°)·S。Rz(30°)=[[√3/2, −1/2, 0],[1/2, √3/2, 0],[0,0,1]]、S=diag(2,6,1/3)。
結果 = [[√3, −3, 0],[1, 3√3, 0],[0,0,1/3]]

同次変換（次元を1つ上げる）

  • 平行移動は「足し算」で、そのままでは行列の掛け算にならず、合成変換を1つの行列にできない。
  • 次元を1つ上げると平行移動も行列の掛け算で表現でき、合成変換できる（同次変換行列）。
[x'] [1 0 0 Tx][x] [y'] = [0 1 0 Ty][y] [z'] [0 0 1 Tz][z] [1 ] [0 0 0 1 ][1]

演習：逆回転・3Dスキュー

▶ z軸周りの逆回転（−θ）の行列 cos(−θ)=cosθ, sin(−θ)=−sinθ より
[[cosθ, sinθ, 0],[−sinθ, cosθ, 0],[0,0,1]]
▶ x軸に沿ってaだけz軸を傾ける3Dスキュー x' = x + a·z, y' = y, z' = z → [[1,0,a],[0,1,0],[0,0,1]]（a = tanα）

2. グラフィックスの基礎知識

CGと画像処理

  • CG：コンピュータ内に仮想的な環境（物体の形状や色、物体にあたる光など）＝シーンを設定し、そのシーンの画像を生成する技術。
  • 画像処理：カメラ・スキャナ等で取り込んだ実世界の画像、またはCG画像をもとに、別の画像に変換したり、画像内の情報を取り出す処理。

ディジタルカメラモデルとCGの対応

カメラCG
[P1] 被写体[M1] 形状モデル（作成＝モデリング）
[P2] 撮影特性（画角、カメラの位置と方向）[M2] 仮想カメラ。像の形は幾何学的モデルで計算
[P3] ライティング、被写体での光の反射[M3] 光の方向・強さ、反射特性。光学的モデルで計算
[P4] 画像の取得（標本化、量子化）[M4] 標本化、量子化
[P5] 取得画像の処理[M5] 画像処理

座標系

  • 2次元／3次元直交座標系：(x,y)、(x,y,z)。3次元には右手系・左手系があり互いに鏡像関係。
  • 極座標系：原点からの距離rと角度θ（3次元は(r,θ,φ)）。
  • 円筒座標系：(ρ,φ,z)。z軸からの距離ρ、z軸まわりの角度φ、z値。

モデリング

  • 三次元図形の形状を数値的に記述すること＝モデリング。記述されたデータ＝形状モデル。
  • 図形を「多角形の集合」で表現する方法＝ポリゴン。頂点の座標とその順序で表せる。
  • 座標は、定義に便利なモデリング座標系で定義し、他の座標系へ座標変換して使う。
  • 立体の外側から見て反時計回りに頂点を並べると決めておけば面の表裏を識別できる。

3. 幾何学的変換

図形の端点・頂点など限られた点のみを変換すればよい（無数の点を変換する必要なし）。

変換式
平行移動x' = x + tx, y' = y + ty
拡大・縮小（原点中心）x' = sx·x, y' = sy·y　（s>1拡大、s<1縮小）
回転（原点中心）x' = x cosθ − y sinθ
y' = x sinθ + y cosθ
行列 [[cosθ, −sinθ],[sinθ, cosθ]]
鏡映x軸に関して：x'=x, y'=−y
y軸に関して：x'=−x, y'=y
直線y=xに関して：x'=y, y'=x
スキュー（せん断）x方向：x' = x + a·y, y' = y（a = tanα）
y方向：x' = x, y' = y + b·x（b = tanβ）
重要 原点以外の点を中心とする拡大・回転 ＝ ①その点が原点に来るよう平行移動 → ②拡大/回転 → ③元の位置へ平行移動し直す。
変換の順番を入れ替えると（一般に）同じ変換にならない。

3次元では、拡大縮小・回転・スキューなどすべての幾何変換は3×3行列を掛けること（線形変換）。z軸周りの回転：[[cosθ,−sinθ,0],[sinθ,cosθ,0],[0,0,1]]

アフィン変換

定義基本変換と、それを複数組み合わせた合成変換をあわせてアフィン変換という。長さや角度は変化するが、直線は直線のまま、平行な直線は平行なまま保たれる。

座標変換

  • 幾何学的変換は2通りに解釈できる：①物体を動かす ②物体は動かさず座標系を動かす。
  • ②のときは符号が反転する（平行移動なら座標系を(−tx,−ty)移動した新座標系での値）。回転でも反転。
  • 利点：同じ図形を多数描くとき、物体を「固有の座標系」で記述しておき、配置する座標系に合わせて座標変換すればよい。

4. 投影変換

ディスプレイや紙など2次元平面に3次元図形を表示するための、3次元→2次元の変換＝投影変換。透視投影と平行投影の2種類。カメラでは像が上下左右反転するが、計算上はレンズの前方に仮想投影面を置く。

透視投影（パース投影）

  • 3次元図形から視点（投影中心・光学中心）に向かう投射線が投影面と交わる位置に像ができる。
  • 遠方のものは小さく描かれ遠近感が生じる。写実的で自然な見え方 → 映画・ゲームで使用。平行線が歪むため形状の正確な把握には不向き。
計算（投影面 z=1）三角形の相似より x : z = x' : 1
x' = x / z、 y' = y / z

平行投影

  • すべての投射線が平行。カメラが無限遠にある透視投影とも解釈できる。
  • 大きさはカメラからの距離によらず同じ。平行線は平行のまま歪まない → 設計製図などで使用。x' = x、 y' = y
  • 直投影（直角投影）：投影方向が投影面に垂直。三面図（正面図・平面図・右側面図）、アイソメ図（底面の直交する2稜線が水平から30°。大まかな形状把握に適する）。
  • 斜投影：投影方向が投影面に垂直でない。α=45°だと正面は元寸法で、奥行き線は正面から45°。奥行き寸法は実寸の√2/2倍になるが、1/2とすることが多い。
  • 3DCGソフトでは両者を切り替えて見られる（Blender: View → Perspective/Orthographic）。

画角（視野角）

  • 投影面上のウィンドウが、視点を中心に何度になるか。
  • 画角大＝広角レンズ効果（物体は相対的に小さく写る）。画角小＝望遠レンズ効果（大きく写る）。
  • 広い画角で視点を被写体に近づけ前面の球を同じ大きさにすると、遠近感が強調される。

遠近法・消失点

  • 透視投影で、3次元空間で平行な直線は投影図上で一点に集中する＝消失点（ただし投影面に平行な直線は平行のまま）。
  • すべての直線がx,y,z軸のいずれかに平行なシーンで、投影面がx・y軸に平行（z軸に垂直）なら、z軸方向の直線のみが消失点を作る＝1点透視。
  • 投影面がx,y,z軸のいずれか1つのみに平行 → 2点透視、いずれにも平行でない → 3点透視。

クリッピングとビューボリューム

  • 無駄な演算を防ぐため、カメラ手前に前方クリッピング面、奥に後方クリッピング面（投影面と平行）を設ける。
  • クリッピング面＋ウィンドウによる6面体＝ビューボリューム。外の物体は表示せず、はみ出した物体ははみ出していない部分のみ表示。
  • 透視投影のビューボリューム＝四角錐台、平行投影＝直方体。

座標系と変換（ビューイングパイプライン）

流れ モデリング座標系 →(モデリング変換)→ ワールド座標系 →(視野変換)→ カメラ座標系（アイ座標系）→(投影変換)→ 投影面 →(ビューポート変換)→ デバイス座標系
  • モデリング座標系：形状を定義しやすいよう物体ごとに設けた座標系。ワールド座標系：世界全体の共通座標系。カメラ座標系：カメラ位置が原点、レンズ方向がz軸方向。
  • レンズ方向をz軸負向きとする右手系（CG向け）と、正向きとする左手系（画像処理向け）がある。
  • 使う変換はすべて「直線→直線」なので、ポリゴンは頂点のみ座標変換して線分で結べばよい。

5. 3原色とカラーモデル

  • 光の波長は連続的。「光の波長はRGBの3つ」は誤り。人間の網膜には「R付近・G付近・B付近」に反応する3種の錐体細胞があり、RGB3つで刺激すれば見え方を「それなりに再現」できる。
  • 加法混色（RGB）：混ぜるごとに明るさが増す（自発光物体の混色）。RGBカラーモデル。
  • 減法混色（CMY）：混ぜるごとに明るさが減る（外光を反射する物体の混色）。Cyan, Magenta, Yellow。印刷ではCMYにK（黒）を加えたCMYK（CMYの混色できれいな黒を出すのが難しいため）。

マンセル表色系

  • RGBは数学的に扱いやすいが人間の感覚に合わない。米国の画家マンセルが色相・明度・彩度の3属性で定義。
  • 色相：色相環を5等分にR, Y, G, B, Pを配置（基本色相）、中間にYR, GY, BG, PB, RP。その間を10等分して計100色相（典型的な色＝5）。
  • 明度：真っ黒(0)〜真っ白(10)を11段階。
  • 彩度：鮮やかさ。無彩色（灰色）〜最も鮮やかな色。色相により最大値が異なる。
  • 表記：色相 明度/彩度（マンセル値）。例：5R4/14 ＝ 色相5R、明度4、彩度14。

HSIカラーモデル

重要マンセルは感覚的に分かりやすいが定量的に扱いづらい → 6点R, Y, G, C, B, Mが同一平面の正六角形に並ぶよう変形。
垂直軸周りの回転角＝色相(H)、垂直軸からの距離＝彩度(S)、垂直軸方向＝明度(I)。画像編集ソフトでこのモデル上で色を操作。

6. 形状モデル

物体は一般に多面体で表現。多面体は頂点・稜線・面の組み合わせ。

モデル特徴できる/できない
ワイヤフレーム頂点と稜線のみ。針金細工。データ量少、接続関係を簡単に表現。草創期によく使用面情報がなく多面体を一意に表現できない（中身の詰まった立方体か空の箱か）。面の干渉演算、陰線・陰面消去ができない
サーフェスワイヤフレーム＋面情報（障子紙を張ったもの）陰線・陰面消去は可。ただし中身の表現がなく、干渉計算で断面を生成できない
ソリッドサーフェス＋中身が詰まった情報。形状を完全に表現断面も正しく生成可。現代のCGはほぼソリッド

どのモデルを使うかと、ディスプレイへの表示方法は独立（ソリッドをワイヤフレーム表示もできる）。

ソリッドモデルの形状表現3種

(1) CSG表現（Constructive Solid Geometry） 直方体・多角柱・多角錐・円柱・球などの基本立体を、集合演算で組み合わせる：和集合(∪)、積集合(∩)（交わった部分）、差集合(−)（一方から他方を除く）。木構造で表され、木の末端が基本立体、分岐が集合演算。
(2) 境界表現（B-rep） 境界（表面）上の頂点・稜線・面とその接続関係に着目して立体を表現。座標値＝「幾何」、接続関係＝「位相」。例：四角錐は5つの面f1〜f5（f1〜f4は3頂点、f5は4頂点へのリンク）。データ構造：位相＝面を構成する頂点の並びの配列、幾何＝頂点座標の配列。頂点を「外側から見て反時計回り」に並べれば面の表裏も表現可。
オイラー操作（位相変更の基本操作）：MEV（新しい頂点と稜線を追加し頂点を分割）、MEF（新しい稜線と面を追加し面を分割）、KEV（MEVの逆）、KEF（MEFの逆）。
(3) スイープ表現 ある平面図形を定められた軌道に沿って移動（水平移動・回転移動など）させたときの軌跡として立体を表現。
現代の3DCGソフトの多くは境界表現を主としつつ、CSGやスイープ操作で設計できる。

7. 曲線・曲面の表現

曲線・曲面は頂点情報のみでは表現できない → 数式でコンパクトに表現。パラメータ制御で設計も容易。

代数曲線

  • 陽関数形式 y = f(x)：1つのxに対し1つのyしか表現できない（扱える曲線に制約）。
  • 陰関数形式 f(x,y) = 0：例 x²+y²−1=0。同一xに複数のyが存在、あるいは対応するyが存在しないこともある。
  • 両者とも xとyの関係を1つの関数で直接表す＝代数曲線。選んだ座標系に表現が依存（xy座標系では回転が煩雑、極座標系では平行移動が煩雑）。
  • 2次曲線：楕円（円含む）・放物線・双曲線。陰関数で ax²+bxy+cy²+dx+ey+f=0。円錐を平面で切った形なので円錐曲線とも。

パラメトリック曲線

  • パラメータt（媒介変数）で x=f(t), y=f(t)。ペン先の時刻tでの位置、その軌跡が曲線。例：x=−t²+2t, y=t²。
  • tを細かく変えながら点列をつなげばよく演算・表示が容易。回転・平行移動も比較的容易。制御点で形状を直感的に変更できる。

ベジエ曲線

  • 制御点の位置で形状設計できるパラメトリック曲線。使用頻度最大は3次ベジエ曲線。
  • n次ベジエ曲線はn+1個の制御点（2次は3点、1次は2点を結ぶ直線）。
3次ベジエ曲線の4性質（P0〜P3） ① 曲線はP0が始点、P3が終点
② 始点で直線P0P1に、終点で直線P2P3に接する
③ 折れ線P0P1P2P3に近い形で、かつそれよりなめらか
④ 曲線は「P0,P1,P2,P3を含む最小の凸多角形」の中に含まれる＝凸包性（干渉の大まかな判定に使える）
x(t) = (1−t)³x0 + 3t(1−t)²x1 + 3t²(1−t)x2 + t³x3 y(t) = (1−t)³y0 + 3t(1−t)²y1 + 3t²(1−t)y2 + t³y3 (0 ≤ t ≤ 1) 2次: P = (1−t)²P0 + 2t(1−t)P1 + t²P2 1次: P = (1−t)P0 + tP1
  • 各項の係数が3次バーンスタイン基底関数。ベジエ曲線は、バーンスタイン基底関数の混合比で制御点の座標を混ぜ合わせたもの。
  • t=0ではP0のみ寄与、t=1ではP3のみ寄与、t=1/3でP1の寄与が最大、t=2/3でP2の寄与が最大。
  • 細分割法：制御点の「中点の中点の中点」をベジエ曲線が通り、そこで2分割される。2分割された曲線は中点が新たな制御点になる。
  • アプリの曲線作図（PowerPoint「頂点の編集」等）：通過点両側のハンドルを操作して変形。P0,P1,P2,P3が3次ベジエの4制御点。

Bスプライン曲線

なぜ必要かベジエ曲線は1つの制御点を動かすと影響が曲線全体に及ぶ（局所制御しにくい）。→ 凸包性を保ちつつ、複数のパラメトリック曲線を滑らかにつなぎ、制御点の影響を局所にとどめる（局所性）よう拡張したのがBスプライン曲線。
  • 基底関数：0次（矩形波）から、隣り合う2関数を重みづけブレンドして次数を1つずつ上げて作る。3次では、ある t で4つの基底関数が存在 → 4つの制御点が影響。

NURBS曲線（Non-Uniform Rational B-Spline）

  • Bスプラインでも円錐曲線を正確には表現できない → 拡張。すべての円錐曲線を正確に表現可能。
  • 各制御点に「引力の強さ」に相当する重みwiをかけた多項式を、重み全体の多項式で割って正規化。基底関数は多項式/多項式（有理式）。

曲面

  • パラメトリック曲面は2つの独立したパラメータ(u,v)の関数。例：半径1の球面 x=cos u cos v, y=sin u cos v, z=sin v（−π≤u≤π, −π/2≤v≤π/2）。uが経度、vが緯度。
  • 双3次ベジエ曲面（Bicubic）：3次ベジエの性質をu方向・v方向の両方に適用。4×4=16個の制御点、端点は4隅の制御点に一致、端点P00で三角形P00P01P10に接する、凸包性を保持。Bスプライン曲面・NURBS曲面も同様に定義可。

レンダリングにおける曲面の扱い

  • 曲面表現は滑らかさ・精度で優位だが、多面体前提のポリゴン処理と相容れない。実際は曲面を細かく分割して多数の小ポリゴンで近似してから処理。
  • GPUでパラメトリック曲面情報を受け取りポリゴンに分割＝ハードウェアテッセレーション。GPUのレンダラを多面体と共通で使え、速度が大幅に向上。

ポリゴン曲面

  • 伝統：パラメトリック曲面として数式表現し、表示時のみポリゴン近似。最近：最初から曲面を多数の細かいポリゴンで表現し、そのまま処理。
  • ポリゴンを再帰的に分割して再分割曲面を構成（初期メッシュ → 再分割1回 → 2回 → 完成）。パラメトリック曲面では難しい「複数個の穴を含む形状」も表現可。
  • 詳細度制御：画素の大きさやリアルタイム性に合わせポリゴン数を削減／視点から遠いポリゴンほど大きく削減（例：69451ポリゴン→約1000→約100）。三角形は頂点が決まれば必ず平面が保証されるためよく使われる。

その他の形状表現

ボクセル3次元物体を小さな立方体（ボクセル）の格子配置で表現。データ構造が簡単で演算効率が良い／高解像度には膨大なデータが必要（HW進化で解決）。各ボクセルの密度や透過率＝ボリュームデータ（CT・MRI・原子構造シミュレーションと親和性が高い）。
八分木2次元の四分木（大きな特徴は大きな正方形、細かい特徴は細分化した正方形）を3次元ボクセルに適用したもの。形状に応じてデータを減らせる。LiDAR（Light Detection And Ranging、レーザの反射時間で距離を測る3次元スキャナ）で得た点群データの情報削減にも利用。
メタボール複数の球体などを融合して滑らかで有機的な曲面を表現。複数のメタボールの濃度分布を加算 → 濃度の等値面を切り出して形状生成。負の濃度で凹形状も可。煙・炎・雲など形が固定されない有機的オブジェクトに有用。
陰関数表現（メタボールの一般化）「空間のどの点がその物体に含まれるか」を定義。判定関数 f(x,y) が0なら表面上、負なら内側、正なら外側。物体の結合演算が容易。内側に正、外側に負の放射基底関数（中心が最大値で離れるほど0に近づく。ガウス関数など）を置き、重み付き和で f を表し、s=f(x,y)=0の等値線を抽出。3次元では s=f(x,y,z)=0 の等値面をマーチングキューブ法で抽出（各頂点のsが基準値より大きいか小さいかからキューブ内の三角形パッチパターンを生成）。さらに s=f(x,y,z,t)（tは時間）で形状モーフィングや流体アニメーションにも使える。

8. 内積・外積

内積（結果はスカラー）

a = (x1,y1,z1), b = (x2,y2,z2) a・b = x1x2 + y1y2 + z1z2 = |a||b| cosθ （θはベクトルの始点を合わせて測る）
  • イメージ：2つのベクトルの長さを「同じ方向の成分」で掛けたもの。同方向ならcos0=1で最大、直交ならcos(π/2)=0、逆向きならマイナス。
  • cosθの符号（鋭角か鈍角か）が分かる → バックフェースカリングで使う。
▶ 練習：a=(2,−3,1), b=(−3,1,2) の内積となす角 a・b = 2×(−3)+(−3)×1+1×2 = −7。|a|=|b|=√14。cosθ = −7/14 = −1/2 → θ = 2π/3（120°）
▶ ひっかけ：∠ABC=60°の三角形で、ベクトルABとBCの内積（各長さ2と1） 始点が揃っていない。ABをBに揃うよう平行移動するとなす角は120°。内積 = 2×1×cos120° = −1

外積（結果はベクトル）

  • 2つのベクトル双方に垂直なベクトル。向きは右ねじの法則（aからbへ小さい角度でねじったときにねじが進む方向）。
  • 大きさ＝2つのベクトルが作る平行四辺形の面積 |a||b| sinθ。
  • 計算：求めたい成分を隠してたすきがけ（y成分は−1倍）。
a × b = ( ay·bz − az·by , az·bx − ax·bz , ax·by − ay·bx )
▶ 練習：a=(4,3,1), b=(2,−1,1) の外積 x: 3·1 − 1·(−1) = 4 ／ y: 1·2 − 4·1 = −2 ／ z: 4·(−1) − 3·2 = −10
→ (4, −2, −10)
▶ 総合：a=(1,1,0), b=(0,2,0)内積＝2、外積＝(0,0,2)

9. レンダリングと陰面消去

レンダリングデータ記述言語やデータ構造で記述された情報から、プログラムで画像等を生成すること。3DCGでは、3次元形状モデルを光の物理的性質に基づき描画し写実的な画像を生成する処理。

レンダリングの処理過程

  1. 透視投影：形状モデルを投影面（2次元）に投影
  2. 陰面消去：手前の面に隠れて見えない面（の一部）を消去。線分表現の図形が「画素の集まり」へ変換（ラスタ化）
  3. シェーディング：光の物理的性質に基づき物体の明るさ(RGB)を計算
  4. マッピング：物体表面にさまざまな効果を付加

(1) バックフェースカリング

  • 物体の内側を向いた面は視点からどうやっても見えない → 除去。面の向きは法線ベクトル（ここでは物体の外側向き）で定義。
  • 法線ベクトルと「法線の起点から視点方向へ向かうベクトル」のなす角が90°を超える（鈍角）面を除去。＝内積が負なら見えない、正なら見える。
  • 半透明ポリゴンには適用できない。
  • 凸状の1物体のみならこれだけでOK。複数物体や凹形状では他の面に隠れる面が残る → 別途陰面消去が必要。
法線ベクトルの求め方 平面の任意の3頂点Pi,Pj,Pkから N = (Pi − Pj) × (Pj − Pk)。単位法線ベクトル N̂ = N / |N|、|N| = √(nx²+ny²+nz²)。
頂点を外側から見て反時計回りに番号付けし、隣接頂点順に引き算してベクトル（P1−P2が①、P2−P3が②）を作り①×②とすると、外積が物体の外側を向く。
Pi − Pj は「Pjを出発してPiに向かうベクトル」。法線の長さには意味がないので1に統一してよい。
▶ 演習1：(0,0,0),(1,0,0),(0,1,1)を通る平面の法線（図で見える側が表面）／視点(0,−1,1)と(1,1,0)で見えるか 青ベクトル(0,1,1)×紫ベクトル(−1,0,0) = (0,−1,1)。単位法線 = (0,−1/√2,1/√2)。
視点(0,−1,1)：頂点(0,1,1)からの視線ベクトル(0,−2,0)、内積 = 2 → 見える
視点(1,1,0)：頂点(0,0,0)からの視線ベクトル(1,1,0)、内積 = −1 → 見えない
▶ 演習2：(1,0,0),(0,1,0),(0,0,1)を通る平面の法線（原点から見えない側が表面）／視点(5,5,−5)と(5,0,−5) 青(−1,0,1)×紫(1,−1,0) = (1,1,1)。単位法線 = (1/√3,1/√3,1/√3)。
視点(5,5,−5)：(1,0,0)からの視線(4,5,−5)、内積 = 4 → 見える
視点(5,0,−5)：視線(4,0,−5)、内積 = −1 → 見えない

(2) 奥行きソート法

  • 視点の奥から手前へ順に、物体をフレームバッファ（表示するRGB値を2次元で保持するメモリ）に重ね書き。（遠いポリゴン→近いポリゴン）
  • 限界：3すくみの状態だと描画順を決定できない／重心で遠近判定しても場所で前後が反転するモデルはNG／凹んだ・貫通したポリゴンもNG／ポリゴン単位より細かい遠近判定はできない。層状のポリゴン群や近景と背景が分かれるモデルなら有効。

(3) スキャンライン法

  • 画像の横1行分＝スキャンライン。スキャンライン単位で陰面消去。
  • 手順：視点と投影面のスキャンラインで構成される走査平面でポリゴンをスライス → 交線の線分（スキャンセグメント）を求める → 両端点を座標値でソートし、端点で区切られた区間（サンプルスパン）を決定 → セグメントが重なるサンプルスパンは視点からの距離で可視セグメントを判定して描画。
  • 特徴：必要メモリが少ない（スキャンライン1本分の端点x座標の配列）／計算量も比較的少ない（隣接画素間でコヒーレンス＝近傍の性質の連続性・類似性を活用、可視判定はサンプルスパンごと）／ただしコヒーレンスを使ったソフト実装は若干複雑。
  • 増分法：辺の傾きmとして Δx = −1/m を1度だけ乗除算で求め、x(i+1) = x(i) + Δx と加算のみで次々に交点を計算。

(4) Zバッファ法

  • フレームバッファに加え、同解像度で各画素の距離を格納するZバッファを追加。
  • Zバッファを「無限遠」に初期化 → ポリゴンを投影し画素ごとにポリゴンの奥行き値とZバッファ値を比較：
    　・ポリゴンの奥行き値が小さい（手前）：フレームバッファに色を格納し、Zバッファを更新
    　・Zバッファ値が小さい（奥）：何もしない
  • 特徴：メモリが多い／アルゴリズムが画一的でハードウェア化しやすい／描画順序に関係なく正しい結果／GPUに向く、DirectX・OpenGLなどが標準サポート。

(5) レイトレーシング法（陰面消去向け）

  • 視点から投影面の画素へ向かう視線（レイ）とポリゴンの交点を計算し、最初に交差するポリゴンを求める（レイキャスティング／ファーストヒットレイトレーシング）。
  • アルゴリズムは簡単でメモリも少ないが、画素ごとの処理で計算量が非常に多い。高速化：バウンディングボリューム（ポリゴン群を囲む球など）で先に交差判定し、交差しないポリゴンを除外。画素ごとに並列処理も可能。

補足：乗除算削減の重要性

演算整数浮動小数点
加算・減算1クロック1〜4クロック
乗算3〜4クロック3〜5クロック
除算10〜90クロック10〜50クロック
  • 除算が最も時間がかかる。HW設計では乗算器を積む／値の範囲が狭ければテーブル引き／2のべき乗の乗除算ならビットシフト（左シフト＝×2ⁿ、右シフト＝÷2ⁿ）で一瞬で演算。
  • 線分描画：y = ROUND((y1−y0)×i/(x1−x0)) + y0 では全点で乗除算が必要。ブレゼンハムのアルゴリズムは加減算と条件分岐のみで線分を描ける。

10. シェーディング

用語の区別シェーディング：光源で照らされたときの陰影(shade)を計算する処理。影付け（シャドウイング）：光が遮られた領域にできる影(shadow)を求める処理。両者は基本的に別処理。

光源の分類

  • 幾何形状：点光源（1点から放射状）、線光源、面光源（面上の全点があらゆる方向に放射）、平行光線（点光源が無限遠にあるとみなせる）。
  • 光と物体の相互作用：直射光（相互作用せず直接到達）、間接光（他物質と相互作用してから照らす）、透過光（物質を通過）、反射光、散乱光（物質内で多重散乱後に出てくる／微粒子で散乱）。

シェーディングモデル（照明モデル）

  • 局所照明モデル：光源からの直接光とそれで照らされる面の関係のみで計算。
  • 大域照明モデル：上記に加え間接光（他物体に反射した光）まで含めて計算。

各成分の式

成分式・性質
環境光I = ka·Ia（ka：環境光に対する反射率、Ia：環境光の強さ）。間接光を非常に大まかに近似した、周囲から来る一様な光。直接光が当たらない部分も真っ暗でなくなる。
拡散反射（平行光線）I = kd·Ii·cosα（α：法線と光源方向のなす角）。ざらざらしたマットな表面。どの方向から見ても明るさ一定（視点に依存せず、光源・面の向き・反射特性で決まる）。kdをRGBごとに持つことで「物体の色」を表現（1に近いほど明るい）。
拡散反射（点光源）I = kd·Iq·cosα / r²（r：光源から点Pまでの距離）。光強度は距離の2乗に反比例（逆2乗の法則）。球の表面積4πr²が距離2rで16πr²になる。
鏡面反射（フォンのモデル）I = W(α)·Ii·cosⁿγ（γ：正反射方向と視点のなす角、W(α)＝鏡面反射率で通常は定数ks、n：ハイライト特性。nが大きいほど鋭い反射）。光沢のあるプラスチック・金属。視点方向で強度が変化。
  • ka+kd=1の割合を変えると陰影が変わる（ka大→のっぺり、kd大→コントラスト大）。
  • 等方性反射：表面の法線まわりに回転させても変化しない通常の鏡面反射。異方性反射：一定方向に磨いた金属や繊維が一定方向に走る布。専用モデルがある。

完全鏡面反射・透過・屈折・散乱

  • 鏡のような完全鏡面反射では他の物体が映り込み、透明・半透明物体では透過して先の物体が映り込む。
  • レイトレーシング法：レイと物体の交点でレイを反射方向と透過・屈折方向に分け、それぞれ最初に交差する物体を求める処理を再帰的に繰り返す（二分木表現）。
  • 散乱・減衰：大気中の空気分子・水蒸気・塵、水中の混濁粒子など。レイに沿って微小距離ずつ進み散乱光を求め、視点までの減衰を考慮して加算するレイマーチング法が必要。

スムーズシェーディング

  • 拡散反射なら1ポリゴン内の明るさは一定 → コンスタントシェーディング。曲面をポリゴン近似していると輝度変化が滑らかでなく、ポリゴン形状が見えてしまう（人間の視覚は輝度変化に敏感）。
  • そこでポリゴン内の輝度を補間して疑似的に滑らかに表示＝スムーズシェーディング。
グローシェーディング（Gouraud）フォンシェーディング（Phong）

11. 影付け（シャドウイング）

  • 点光源・平行光線：影の領域と光の当たる領域がはっきり分かれる（本影のみ）。
  • 面光源・線光源など大きさを持つ光源：光が全く届かない本影と、光の一部だけが届く半影が生じる。半影は本影に近づくにつれ順に暗くなる（本影の半分の明るさ、ではない）。例：月食。

点光源・平行光線の影の算出

手法方法
レイトレーシング法各画素に表示される物体面上の点と光源を結び、間に光を遮る物体があれば影。簡単だが画素ごとに判定するため時間がかかる。
スキャンライン法陰面消去と影付けを同時に行える。描画中のスキャンラインで面S1の可視線分P1〜P3について、光源との間にある物体（面S2）による影区間を計算し、影区間の線分を影にする。
Zバッファ法① 光源の位置を視点としてZバッファ法で光源から物体面までの距離を画素ごとに求める＝シャドウマップ。② 通常の視点から描画時、各可視点に対応するシャドウマップ値と「光源から可視点までの距離」を比較。シャドウマップの距離のほうが短い＝間に他物体がある＝影（その光源の光は輝度に加算しない）。

大きさを持つ光源

  • 本影・半影を反映した処理は複雑で計算時間もかかる。
  • 近似：光源表面にいくつかの点光源を配置し点光源の集合として近似（密度が低いと影を生じさせる物体を検出できず誤差大）。
  • 光源を球とし、球と計算点でできる円錐と物体の交差の程度から影の度合いを決める方法。
  • 積分法：半影の明るさは、その点から光源を見たときの光源の可視領域の大きさに依存。

12. マッピング

レンダリング最終段階で物体表面に模様や凹凸などの効果を付加。直接ポリゴンでモデル化するのは煩雑で計算時間もかかるため、パターンを貼り付けたように表示する。

2次元の画像・関数を3次元面へ3次元空間の画像・関数を3次元面へ
テクスチャマッピング、バンプマッピング、環境マッピング などソリッドテクスチャリング

テクスチャマッピング

  • 貼る模様・画像＝テクスチャ（実写・CG・乱数/フラクタル/1/fゆらぎで生成した自然物特有パターン等）。2次元テクスチャを3次元の面・曲面に貼る。
  • 投影による方法：投影方向を逆にし、スクリーン上のテクスチャを物体面に投影（視点からプロジェクタで投射するイメージ）。平行投影ではスクリーン面と垂直に近い面でテクスチャが伸びる。円筒座標投影・球座標投影もある。
  • 極座標変換による方法：物体中心に極座標系の原点を置き、(x,y,z)→(r,θ,φ)に変換して貼る。球に使うが2つの極付近でテクスチャが圧縮され不自然になる場合あり。
  • パラメータ座標による方法：曲面上の点を(u,v)（0≤u,v≤1）で表しテクスチャ座標と対応付ける。形状と色・模様を分けて扱えテクスチャ入れ替えが容易。ただし歪む、広い面に繰り返し貼ると継ぎ目、縮小しすぎるとエイリアシングが起きる。
  • エイリアシング：画像の高周波成分が縮小画像に悪影響を及ぼす。高周波を抑えるフィルタリング＝アンチエイリアシング。ミップマップ＝元画像の1/2、そのまた1/2…を事前に用意（元のRGB画像の4/3のメモリ量）。
バンプマッピング模様のかわりに凹凸をマッピング。物体表面の形状は変えず、テクスチャに応じて面の法線方向を変化させ、シェーディング時の明るさを変えて凹凸感を表現。（形状を微小に変化させる方法はディスプレイスメントマッピング）
環境マッピング（リフレクションマッピング）反射による周囲の映り込みを疑似的に表現。物体を囲む半径の大きな仮想球や仮想立方体の内面に周囲環境のテクスチャを貼り、物体面で反射したレイと仮想球/立方体の交点のテクスチャを貼る。レイトレーシングより少ない計算量で完全鏡面反射を疑似表現できるが、1回の反射しか扱えず物体どうしの映り込みは表現できない（反射面の近くの物体の映り込み方が異なる）。
ソリッドテクスチャリング大理石や木材の模様を各面に貼ると不連続な場所が生じる／球に極座標でマップすると極に集中する、という問題を解決。3次元空間で定義される関数で3次元的なテクスチャを計算で生成し、物体形状に合わせて切り出すように表示。例：木目は同心円状パターンを直方体状に切り出し、中心線と円を偏らせ、奥行き方向にねじりを与え、中心を傾ける。

13. イメージベーストレンダリング（IBR）

  • 従来のCGで写実的な画像を作るには、細部まで精密な3次元形状モデルと光学的に精密なシェーディングモデルが必要 → モデリングの労力・計算時間が増大。
  • そこで実写画像を含む画像を入力に、それに基づく3次元的表現を可能にするのがIBR。3次元形状モデルを使う／使わないなど幅広い。近年は深層学習利用も含め進展。

  • テクスチャマッピングアプローチ：外形を表す簡易形状モデルに実写画像をテクスチャマッピング。詳細・シェーディングは実写テクスチャで表現。
  • 画像再投影アプローチ：レンジファインダ（ステレオ視差やToF: Time of Flightで距離測定）等で画素ごとの奥行き値を求め、再投影で別視点の画像を生成。または複数画像間の画素単位の動き（オプティカルフロー）から生成。元画像に存在しない画素が穴あきになる問題 → レイヤデプスイメージ（奥行き値を何層にも持つ）で軽減。

フォトグラメトリー

流れ多方向から撮影した複数写真から実物の形状・質感を3次元モデルとして復元。
① SfM（Structure from Motion）：共通の特徴点を探し、各写真の撮影位置・角度を推定 → 疎な点群
② MVS（Multi-View Stereo）：推定カメラ位置から多視点ステレオ解析で密な点群を生成（カメラ位置が既知なので探索が限定される＝エピポーラ拘束）
③ メッシュ化：点をつなぎ面を張り、ポリゴンの立体に
④ テクスチャ生成：写真の色情報をメッシュ表面に貼る
写真は十分な重なり（60〜90%のオーバーラップ）が必要。
限界：光沢面・透明物・単色で模様の少ない面・動いている対象は形状を正しく復元しにくい。

NeRF と 3Dガウシアンスプラッティング

NeRF3Dガウシアンスプラッティング
表現3次元空間の位置ごとの色と密度を出力するニューラルネットワークを学習。新視点画像はNNの推論で生成3次元空間を「透明度・色・奥行き・方向」情報を持つ楕円体の集合で表現（絵筆で楕円体を描いて3D空間を再現するイメージ）
長所破綻の見えにくい滑らかな補間画像境目が滑らかで非常に自然。水など透明感のあるもの・反射も表現しやすい。深層学習不要で高速な学習（数十分程度）・生成
短所学習に非常に長時間（数時間〜日単位）、推論にも数秒〜数分ポリゴンベースでないため完成モデルの形状編集や計測には不向き

3DGSの「学習」：初期配置したスプラットと正解画像を比較し、近づく方向に位置・形・色の修正、スプラットの追加・複製・分割・消去を行う。

14. 直前チェック（一問一答）

透視投影の計算式は？投影面z=1で x'=x/z、y'=y/z。平行投影は x'=x、y'=y。
アフィン変換で保たれるものは？直線は直線のまま、平行線は平行のまま。長さと角度は変わる。
原点以外を中心とする回転の手順は？中心を原点へ平行移動 → 回転 → 元へ平行移動。順序を替えると結果が変わる。
平行移動を行列積で表すには？次元を1つ上げる（同次変換行列）。合成変換が1つの行列で表せる。
透視投影/平行投影のビューボリュームは？透視＝四角錐台、平行＝直方体。
ワイヤフレームの欠点は？面情報がなく一意に表現できない／面の干渉演算・陰線陰面消去ができない。
サーフェスとソリッドの違いは？サーフェスは中身の情報がなく断面を生成できない。ソリッドは中身があり断面も正しく生成。
境界表現の「幾何」と「位相」は？幾何＝頂点座標。位相＝頂点・稜線・面の接続関係。
ベジエ曲線の欠点とBスプラインの改善点は？1制御点の移動が曲線全体に影響。Bスプラインは局所性を持つ（凸包性は保持）。
NURBSがBスプラインより優れる点は？重みを持ち、円錐曲線を正確に表現できる。
双3次ベジエ曲面の制御点数は？4×4＝16個。
バックフェースカリングの判定は？法線と視線方向ベクトルの内積が負（鈍角）なら見えない＝除去。
奥行きソート法・スキャンライン法・Zバッファ法・レイトレーシング法の特徴は？ 奥行きソート：遠→近の重ね書き、ポリゴン単位でしか判定できず3すくみ等に弱い。
スキャンライン：走査線単位、メモリ少・コヒーレンス活用。
Zバッファ：メモリ多、描画順序不問、GPU向き。
レイトレーシング：画素ごとにレイ、メモリ少・計算量大、バウンディングボリュームで高速化。
拡散反射／鏡面反射／環境光の式は？環境光 I=ka·Ia。拡散反射（平行）I=kd·Ii·cosα、（点光源）I=kd·Iq·cosα/r²。鏡面反射（フォン）I=W·Ii·cosⁿγ。
グローとフォンの違いは？グロー＝頂点の明るさを補間（軽い、ハイライトが欠落しうる）。フォン＝法線を補間し画素ごとに輝度計算（重いがリアル）。
本影と半影は？大きさのある光源で生じる。本影＝光が全く届かない部分、半影＝光の一部だけ届く部分。
Zバッファ法での影付けは？光源視点のシャドウマップを作り、可視点の光源からの距離とシャドウマップ値を比較。マップの値が短ければ影。
バンプマッピングとディスプレイスメントマッピングの違いは？バンプ＝法線を変えて見かけの凹凸（形状は不変）。ディスプレイスメント＝実際に形状を微小変位。
環境マッピングの制約は？1回の反射のみ。物体どうしの相互映り込みは表現できない。
ソリッドテクスチャリングが解決する問題は？面ごとのマッピングで模様が不連続になる／球の極にテクスチャが集中する問題。3次元関数から切り出す。
フォトグラメトリーの処理順は？SfM（疎な点群）→ MVS（密な点群）→ メッシュ化 → テクスチャ生成。
NeRFと3DGSの学習時間の違いは？NeRFは数時間〜日単位、3DGSは数十分程度（深層学習不要）。
